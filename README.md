# OpsPilot 🚀

**Context-aware AI Incident Investigation Assistant for Atlassian**

OpsPilot helps engineering teams investigate software incidents by connecting information across Jira, Confluence and Atlassian Teamwork Graph.

Powered by Rovo and built on Atlassian Forge, OpsPilot identifies relevant engineering context, generates evidence-backed root-cause hypotheses and recommends actionable investigation steps.

## 🎯 Problem

Developers often waste time manually searching through Jira issues, historical incidents and technical documentation when investigating production problems.

## 💡 Solution

OpsPilot brings relevant engineering context together and helps developers understand incidents and decide what to investigate next.

## ✨ Planned Features

- Jira incident investigation panel
- Rovo-powered incident investigation agent
- Related incident and issue discovery
- Confluence runbook retrieval
- Evidence-backed root-cause hypotheses
- Recommended investigation steps
- Teamwork Graph context integration
- Human-approved Jira actions

## 🛠️ Technology Stack

- Atlassian Forge
- React and TypeScript
- Rovo Agents, Skills and Actions
- Jira APIs
- Confluence APIs
- Teamwork Graph API
- Forge Functions and Storage
